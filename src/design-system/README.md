# Aliado Design System

Fundação visual oficial do Aliado V1 Beta.

- Tokens globais: cores, glow, spacing, radius, typography, shadows
- Componentes reutilizáveis: Button, Card, Input, Avatar, Badge, BottomTab, SectionTitle, EmptyState, MetricCard, GradientCard, NetworkCard
- Layouts base mobile-first: SafeArea, PhoneContainer, MobileContainer
- Tema: preto profundo, marrom premium, laranja Aliado, glow laranja suave
- Pixel-perfect conforme wireframe aprovado
- Tipagem forte, acessibilidade básica

**Uso:**
```ts
import { Button, Card, colors } from 'src/design-system';
```
